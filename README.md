# Global CO₂ Policy Monitoring Dashboard using Tableau and Power BI

This project uses Tableau and Power BI to analyse global CO₂ emissions and policy-related indicators from 1990–2024.

The aim was to build an interactive visual analytics dashboard that helps users compare countries, understand long-term emissions trends, examine emissions sources, and identify policy-priority areas.

The project demonstrates skills in dashboard design, data visualisation, business intelligence, data storytelling, and comparative BI tool implementation.
